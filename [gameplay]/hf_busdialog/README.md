# HF Bus Dialog System

Диалоговая система на Svelte для работы с автобусником (hf_busjob).

## Описание

Это ресурс предоставляет современную диалоговую систему с красивым UI на основе Svelte для взаимодействия игроков с NPC. Система разработана согласно требованиям геймдизайна для создания иммерсивного опыта взаимодействия.

## Возможности

- 👤 **3D имя над головой NPC** - каждый NPC имеет уникальное имя (например, "Густаво Ортега")
- ⌨️ **Взаимодействие через E** - простое и интуитивное управление
- 💬 **Подсказка внизу экрана** - красивая анимированная подсказка по центру
- 🎥 **Камера от первого лица** - при диалоге NPC отображается слева на экране
- 🎨 **Современный UI на Svelte** - правая панель с раскрывающимися диалогами
- 📋 **Аккордеон-диалоги** - кликабельные заголовки с раскрывающимся содержимым
- 🔘 **Кнопки действий** - для диалогов с функционалом (трудоустройство и т.д.)
- 🌐 **Легкая настройка** - все NPC и диалоги настраиваются через config.lua

## Установка

1. Поместите ресурс в папку `[gameplay]`
2. Убедитесь, что `hf_busjob` установлен
3. Ресурс автоматически загрузится через `ensure [gameplay]` в server.cfg

## Зависимости

- qbx_core (для интеграции с автобусником)
- ox_lib

**НЕ требуется:**
- ~~ox_target~~ или ~~qb-target~~ - система работает на E-взаимодействии

## Конфигурация

Откройте `config.lua` для настройки:

```lua
Config.InteractionDistance = 2.5 -- Расстояние взаимодействия
Config.Camera.enabled = true -- Включить/выключить камеру
Config.Camera.fov = 50.0 -- Поле зрения камеры

-- Пример конфигурации NPC
Config.peds = {
    ['bus_dispatcher'] = {
        name = 'Густаво Ортега', -- Имя над головой
        model = 's_m_m_cntrybar_01',
        coords = vector4(1716.0, 3325.22, 41.22, 195.0),
        dialogs = {
            {
                id = 'greeting',
                title = 'Приветствие',
                text = 'Текст диалога...',
                expanded = false,
                actions = { -- Опционально
                    {
                        label = 'Устроиться',
                        event = 'event_name',
                        type = 'server',
                        closeAfter = true
                    }
                }
            }
        }
    }
}
```

## Как работает система

### Взаимодействие с NPC

1. **Приближение к NPC** - над головой появляется имя NPC
2. **Близкое расстояние** - внизу по центру появляется подсказка "Нажмите [E] чтобы поговорить"
3. **Нажатие E** - открывается диалоговое окно:
   - HUD скрывается
   - Камера переключается на вид от первого лица (NPC слева)
   - Справа появляется панель с диалогами
4. **Взаимодействие с диалогами**:
   - Клик на заголовок диалога раскрывает его содержимое
   - Для функциональных диалогов появляются кнопки действий
   - ESC или кнопка X закрывают диалог

### Структура диалогов

Каждый диалог состоит из:
- **title** - заголовок (всегда виден)
- **text** - содержимое (раскрывается по клику)
- **actions** - кнопки действий (опционально)

## UI Особенности

### Правая панель
- Ширина: 450px
- Темный полупрозрачный фон
- Плавная анимация появления справа
- Скроллбар для длинного списка диалогов

### Диалоги (Аккордеон)
- Заголовки всегда видны
- Клик раскрывает содержимое
- Плавная анимация раскрытия
- Подсветка при наведении и активности

### Кнопки действий
- Градиентный фон
- Эффект волны при наведении
- Поднятие при hover
- Свечение для активных элементов

## API

### Экспорты

```lua
-- Открыть диалог
exports.hf_busdialog:OpenDialog({
    ped = pedEntity,
    npcName = 'Имя NPC',
    dialogs = {
        {
            id = 'dialog1',
            title = 'Заголовок',
            text = 'Содержимое',
            actions = {
                {
                    label = 'Кнопка',
                    event = 'event_name',
                    type = 'client', -- или 'server'
                    closeAfter = true
                }
            }
        }
    }
})

-- Закрыть диалог
exports.hf_busdialog:CloseDialog()

-- Заспавнить педа из конфига
exports.hf_busdialog:SpawnPed('ped_id')
```

### События

```lua
-- Для bus integration
RegisterNetEvent('qbx_busjob_new:client:jobStarted')
RegisterNetEvent('qbx_busjob_new:client:jobQuit')
```

## Технические детали

### Технологии
- **Frontend**: Svelte 4.2
- **Build**: Vite 5.0
- **Стили**: Inline CSS (scoped)
- **Backend**: Lua 5.4

### Оптимизация
- Динамический sleep для 3D текста (500ms когда далеко, 0ms когда близко)
- Скрытие HUD только при открытом диалоге
- Плавные анимации без лагов
- Легковесный bundle (~13KB total)
